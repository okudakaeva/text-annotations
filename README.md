# Text Annotations 🖍️💬✨

**«Читать текст без заметок на полях — всё равно что коммитить в `main` без тестов: вроде бы прочитал, а смысла в проде не осталось!»**

— *Архитектор Смысловой Разметки*

**Text Annotations** — это минималистичная студия вдумчивого чтения, редактор документов и система микро-разметки смыслов на **Angular 21**, которая превращает бесконечные простыни текста в структурированную карту мыслей с цветовой кодировкой и мгновенными аннотациями.

Никаких комбайнов на полгигабайта ради одной галочки и никаких утечек памяти в DOM: только чистый реактивный **Angular 21 (Signals + OnPush)**, нативный **Browser Selection API**, хирургическая санитизация через **DOMPurify** и **100 / 100 / 100 / 100** в Google Lighthouse.

## 🎭 Архитектурная Драматургия и Инженерная Магия

Приложение построено без тяжёлых сторонних UI-фреймворков (никаких Material, PrimeNG и прочих коробок с чужим CSS) — каждый интерактивный узел написан нативно и под полным контролем:

* **Хирургия живого текста (`Selection API` + `TreeWalker` + `Range.surroundContents()`):** Выделяйте любые фрагменты — хоть одно слово, хоть несколько абзацев со вложенными `<strong>`, `<em>` и `<u>`. Система автоматически подрезает случайные пробелы по краям выделения, обходит текстовые узлы через `TreeWalker` (`NodeFilter.SHOW_TEXT`) и аккуратно оборачивает каждый фрагмент в `<mark data-annotation-id="...">` с единой иконкой `ⓘ` в конце цепочки. При отмене диалога, удалении заметки или нажатии `Escape` разметка разворачивается обратно в чистый текст с нормализацией узлов (`Node.normalize()`).
* **Реактивный `contenteditable` и синхронизация чтения (`ReactiveContentEditable` & `ArticleReadonlySync`):** Кастомный `ControlValueAccessor` связывает `contenteditable`-редактор с Angular Reactive Forms (с очисткой вставки из буфера до `text/plain` и дедупликацией эмитов). Для режима просмотра отдельная директива `ArticleReadonlySync` отслеживает подтверждённые аннотации через `MutationObserver` и автоматически сохраняет очищенный HTML статьи.
* **Умное позиционирование с защитой от побега за экран:** Контекстная кнопка создания аннотации (`AnnotationButtonService`) вычисляет нижний прямоугольник выделения (`getClientRects()`) и зажимает координаты в пределах viewport (`clamping`). Всплывающий тултип (`TooltipService`) предварительно измеряет клон реального DOM-узла через `requestAnimationFrame` для расчёта размеров без погрешностей и автоматически переворачивается вниз, если над аннотацией не хватает места.
* **Динамические оверлеи нового поколения (`createComponent` + `inputBinding` / `outputBinding`):** Модальные окна и тултипы монтируются в корень документа через современный API Angular 21 с блокировкой скролла без скачков страницы, закрытием по `Escape` (с откатом несохранённых меток) и нативной CSS-анимацией выхода `animate.leave`.
* **Глобальный надзиратель за стилями (`AnnotationsRenderer`):** Единый сервис на базе `MutationObserver`, `queueMicrotask` и реактивного сигнала в `AnnotationsService` отслеживает появление новых меток `<mark>` в DOM, применяет цвета через CSSOM и автоматически подбирает контрастный цвет текста по формуле YIQ с O(1)-кэшированием.
* **Параноидальная XSS-гигиена (`DOMPurify` + `SafeHtmlWithAnnotationsPipe`):** Весь пользовательский HTML пропускается через строгий белый список тегов и атрибутов — ни один `<script>`, `onclick` или левый `<span>` не проскочит в рендер.
* **Чистая реактивность и ленивая загрузка Angular 21:** Весь слой компонентов переведён на `ChangeDetectionStrategy.OnPush`, сигналы (`signal`, `computed`, `effect`, `input`, `output`, `viewChild`), ленивую загрузку маршрутов через `loadComponent()`, `withComponentInputBinding()` и автоматическую отписку `takeUntilDestroyed()`.

## 🎮 Что умеет система

* **Управление библиотекой статей:** Создание, просмотр, редактирование и удаление документов с мгновенным персистентным сохранением и каскадной очисткой связанных данных.
* **Полный CRUD аннотаций в два клика (как при чтении, так и при редактировании):** Выделили фрагмент → нажали всплывающую кнопку `💬` → выбрали цвет маркера и вписали комментарий → получили подсвеченный фрагмент с интерактивной иконкой `ⓘ`. Любую заметку можно отредактировать (с обновлением цвета и текста) или удалить прямо из тултипа аннотации или диалога.
* **Умные аннотации (`TooltipContainer`):** Клик по `ⓘ` открывает контрастную карточку заметки с защитой от гонки асинхронных запросов (`requestCounter`), закрытием по повторному клику, клику вне области или скроллу, а наведение подсвечивает все фрагменты составной аннотации единым контуром.
* **Боковая панель-навигатор (`AnnotationsSidebar`):** Кнопка-сэндвич с бейджем счётчика в заголовке плавно раздвигает сетку чтения и открывает панель со всеми заметками статьи, отсортированными строго по порядку их появления в тексте. Наведение на карточку подсвечивает связанные фрагменты `<mark>` в статье, а клик плавно прокручивает экран к нужному месту (с ускоренной докруткой крайних карточек списка через `requestAnimationFrame`) и сразу открывает тултип.

## 🚀 Быстрый старт

```bash
# 1. Клонируйте репозиторий и перейдите в папку проекта
git clone https://github.com/okudakaeva/text-annotations
cd text-annotations

# 2. Установите зависимости
npm ci

# 3. Запустите dev-сервер (http://localhost:4200)
npm start

# 4. Прогоните юнит-тесты (Vitest + jsdom)
npx ng test --watch=false

# 5. Соберите production-бандл
npm run build
```

## 🏛 Инженерные Принципы Проекта

1. **Zero UI-Bloat:** Никаких внешних библиотек компонентов — весь интерфейс (диалоги, тултипы, тулбары, прелоадеры) весит считанные килобайты и управляется через CSS Custom Properties.
2. **Strict TypeScript & Templates:** Включены `strict: true`, `strictTemplates: true`, `noPropertyAccessFromIndexSignature: true` и `noImplicitOverride: true`.
3. **Автоматический контроль качества:** Каждый пуш в `main` прогоняет юнит-тесты на **Vitest**, собирает production-бандл, деплоит его на **GitHub Pages** и обновляет SVG-счётчики **Google Lighthouse**.
